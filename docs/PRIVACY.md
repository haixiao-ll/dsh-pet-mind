# 隐私说明：数据从哪来、到哪去、留多久

> 本文是技术说明与合规提示，**不构成法律意见**。不同法域（中国《个人信息保护法》、欧盟 GDPR 等）
> 对"屏幕内容是否属于个人信息""是否需要单独同意"有不同要求，请结合你的使用场景自行判断。

## 1. 数据清单

| 数据 | 来源 | 存放位置 | 保留期 |
|---|---|---|---|
| 屏幕帧（JPEG，1600×900） | 桌面 Helper `desktopCapturer` | **仅内存** | 转文字后立即丢弃（进程内不保留） |
| OCR 文字 | Windows 自带 OCR（本地） | 仅内存 | 用于一次建议生成，函数返回即释放 |
| 前台应用名 / 窗口标题 | Windows `GetForegroundWindow` | 仅内存 | 标题用完即弃，**不落盘、不进日志** |
| 建议文案 | 文本模型返回 | 内存 + 状态接口 | 最近一条，进程重启清空 |
| 上下文快照（仅 token 数/窗口/模型名） | DSH 的 usage / context | `$DSH_HOME/dsh-pet/mind-state.json` | 覆盖写，超过 24 小时不恢复；删除文件即清 |
| 工作记忆 | 会话事件 → 本地抽取摘要 | `$DSH_HOME/dsh-pet/memory/work/*.md` | 直到你删除 |
| 陪伴记忆 | 聊天里"称呼/偏好/约定"句 | `$DSH_HOME/dsh-pet/memory/companion/*.md` | 直到你删除 |
| 记忆索引 | 自动生成 | `memory/INDEX.md` | 随记忆更新 |
| 宠物对话历史 | 你与宠物聊天 | `memory.json` | 直到你删除 |
| 配置 | 你编辑/设置页保存 | `main-config.jsonc` | 直到你删除 |
| 日志（控制台） | 插件自身 | DSH 进程输出 | **不含窗口标题、不含 OCR 文字**；建议文案只记"已发送" |

## 2. 出网边界（最重要）

| 模式 | 谁会离开本机 |
|---|---|
| `mind.enabled=false` | 无（整层不启动） |
| `vision.enabled=false`（手动关闭后） | 无（连截帧都不做） |
| `vision.enabled=true` + `mode="ocr"`（**出厂默认**） | **只有 OCR 文字 + 前台应用名**，发给你配置的文本模型；图像不离开 |
| `vision.mode="model"`（可选，默认关） | 一帧 JPEG（640/1600 宽）+ 应用名，发给你配置的视觉端点 |

- `mode:"ocr"` 下**图像永不离开本机**：截图 → 内存 → 本地 OCR → 丢弃；
- 文本模型由 DSH 的模型配置决定（`chatModel` / 当前对话模型）；模型服务商的数据处理适用其自身条款；
- 没有遥测、没有统计上报、没有第三方 SDK 埋点。

## 3. 用户控制

| 想要 | 怎么做 |
|---|---|
| 整层关闭 | `mind.enabled=false`，或设置页关掉相关开关（如已暴露） |
| 不碰像素 | 设 `vision.enabled=false`（默认是开的，帧只在内存且只截一帧） |
| 临时停止采集 | 设置页「隐私暂停」按钮，或 `POST /dsh-pet-7340/mind/pause?paused=1` |
| 追加敏感应用 | `mind.privacy.apps` / `titlePatterns` |
| 清空记忆 | 删除 `$DSH_HOME/dsh-pet/memory/`（工作+陪伴+索引一起清） |
| 清空对话历史 | 删除 `memory.json` |
| 完全卸载 | 用插件管理卸载；再删 `$DSH_HOME/dsh-pet/` |

## 4. 最小必要与目的限制

- 只采"前台应用名 + 窗口标题 + 空闲时长"用于判断"你还在不在、在哪个页面"；
- 只在**一次停留到期**时截一帧，用于"这个页面在讲什么"；
- 不采集剪贴板、键盘输入、输入法内容、摄像头、麦克风、文件内容；
- 截帧会**裁掉桌宠自己的窗口**，减少无关内容。

## 5. 合规提示

- **在工作场所/他人设备上使用**：屏幕内容可能包含同事、客户或公司的信息。中国《个人信息保护法》
  要求"告知—同意""最小必要""目的限制"；劳动关系下还需遵守劳动法/规章制度，员工监控通常需要
  明示告知与合理性依据。**不要把它当作员工监控工具。**
- **处理他人个人信息**：请确认你有合法依据；不要把记忆文件、OCR 文本上传到公共仓库或第三方。
- **向境外模型服务商发送文字**：可能构成个人信息出境，需自行评估服务商所在地与合规要求。
- **未成年人**：不建议在未成年人设备上长期开启屏幕感知。
- **涉密/受限材料**：不要使用任何云端模型链路；请关闭 `vision` 或改用纯本地模型。

## 6. 安全边界（诚实说明）

- 帧只在内存中，但**操作系统可能把进程内存换页到磁盘**（pagefile）；任何用户态程序都无法完全避免；
- 本地 OCR 由 PowerShell 子进程执行，图片经 stdin 传入、不写临时文件；
- 插件运行在 DSH 进程内，权限等同于你的用户账户；**不会**请求管理员权限。

## 7. 与第三方插件的关系

- 本项目**不打包** `dsh-vision-router`；它的安装、配置与数据流向由它自己负责；
- 本项目不调用它的接口；两者可以同时安装，但请分别阅读各自的隐私说明。
